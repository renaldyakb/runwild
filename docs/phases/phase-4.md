# Fase 4 · Riwayat, Home, Progress, Profil

Sumber: PRD §6.5–6.7, F-11–F-15.

| Tugas | Selesai bila |
| --- | --- |
| T4.1 · Daftar aktivitas lokal (selesai) | Sesi selesai per akun, kelompok bulan, filter bebas/interval, 20 per halaman, thumbnail rute, state loading/empty/error/offline |
| T4.2 · Detail aktivitas (selesai) | Buka detail, rute/split/interval/catatan, ubah judul, hapus dengan konfirmasi dan sinkron perubahan |
| T4.3 · Pemulihan riwayat cloud (selesai) | Unduh riwayat Firestore ke cache lokal, pagination, deduplikasi dan konflik offline |
| T4.4 · Home dan minggu (selesai) | Agregat nyata, grafik tujuh hari, target mingguan, rekomendasi berdasarkan sesi |
| T4.5 · Progress (selesai) | Statistik mingguan/bulanan dan rekor pribadi dari aktivitas |
| T4.6 · Profil dan pengaturan (selesai) | Profil, satuan, preferensi suara/getar, privasi |
| T4.7 · Hapus akun (selesai) | Konfirmasi ganda; hapus data lokal, Firestore/Storage dan Auth |

DoD: semua state layar, agregat cocok dengan aktivitas, penghapusan data teruji.
Pengguna mengizinkan Fase 4 dimulai sebelum uji fisik Fase 2–3; uji tersebut
tetap tertunda dan wajib sebelum menyatakan MVP siap beta.
