# Fase 2 · Tracking inti

Sumber: PRD F-03–F-06, §4.1–4.2, §6.1 dan §11.

| Tugas | Selesai bila |
| --- | --- |
| T2.1 · Izin aktivitas | Penjelasan izin sebelumnya, lokasi saat Mulai Lari, notifikasi opsional, pemulihan lewat pengaturan |
| T2.2 · Mesin tracking | Jarak, durasi dan pace dihitung dari sampel valid dan jam monoton |
| T2.3 · GPS dan background | Lokasi tetap direkam saat layar mati pada Android dan iOS |
| T2.4 · Sesi aktif | Countdown, angka utama, jeda dan kunci layar berfungsi |
| T2.5 · Persistensi dan pemulihan | Sesi tersimpan dan dapat dilanjutkan setelah aplikasi ditutup |

DoD: jalan lapangan 30 menit dengan galat jarak ±3%, layar mati 60 menit
pada Android dan iOS, pulih tanpa kehilangan data, cakupan mesin ≥90%.
