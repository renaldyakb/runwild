# Fase 3 · Interval, ringkasan, bagikan

Sumber: PRD §6.2, F-07–F-10 dan Fase 3.

| Tugas | Selesai bila |
| --- | --- |
| T3.1 · Mesin interval | Dart murni, jam monoton injeksi, validasi batas, semua transisi dan jeda diuji, simulasi 60 menit tanpa drift |
| T3.2 · Pengaturan interval | Preset, konfigurasi kustom, total durasi, pilihan mode dan integrasi layar aktif/pemulihan |
| T3.3 · Panduan fase | TTS, fallback nada, getar/notifikasi dan audio ducking |
| T3.4 · Ringkasan sesi | Statistik, split, ringkasan interval dan penilaian rasa sesi |
| T3.5 · Bagikan | Kartu 3 tema × 2 format, simpan/bagikan dan privasi rute |
| T3.6 · Sinkron | Antrean offline ke Firestore/Storage, idempoten tanpa duplikasi |

DoD fase: panduan tepat ≤1 detik selama 60 menit layar mati, musik tidak
berhenti saat panduan, kartu benar di Instagram/WhatsApp, sinkron tanpa duplikasi.
Uji lapangan dan pemulihan Fase 2 tetap wajib sebelum klaim siap MVP.
