# Archivo

Sumber: https://github.com/google/fonts/tree/main/ofl/archivo
Diunduh 2026-11-14; lisensi SIL OFL disertakan sebagai OFL.txt.

Archivo-Regular.ttf berasal dari Archivo[wdth,wght].ttf.
Archivo-Italic.ttf berasal dari Archivo-Italic[wdth,wght].ttf.
Keduanya variable font, bukan aset yang diunduh saat runtime.

GSUB Archivo-Regular memuat tnum (tabular figures), diverifikasi dari tabel
OpenType berkas font. Display menggunakan variasi wght 900; teks UI tegak.
